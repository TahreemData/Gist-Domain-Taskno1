# Gist-Domain-Taskno1# Retail Sales Data Analysis

 Project Overview

This project focuses on analyzing a **Retail Sales Dataset** using Python. The main objective is to clean, explore, and analyze retail sales data and extract useful business insights through statistical analysis and data visualization.

The project covers important steps of the data analytics workflow, including:

- Data loading and inspection
- Data cleaning
- Missing value analysis
- Duplicate detection
- Data validation
- Descriptive statistics
- Unique value analysis
- Outlier detection
- Exploratory Data Analysis (EDA)
- Data visualization
- Business insights
- Exporting cleaned data

---

## 🎯 Objectives

The main objectives of this project are:

1. Understand the structure of the retail sales dataset.
2. Check and handle data quality issues.
3. Identify missing values and duplicate records.
4. Analyze numerical and categorical variables.
5. Calculate descriptive statistics.
6. Detect potential outliers using the IQR method.
7. Create meaningful visualizations.
8. Identify sales patterns and trends.
9. Generate useful business insights from the data.

---

## 📂 Dataset

The dataset contains retail order information with columns such as:

| Column | Description |
|---|---|
| OrderID | Unique identification number of an order |
| Date | Date of the order |
| CustomerID | Unique customer identification |
| Product | Product purchased |
| Quantity | Number of units purchased |
| UnitPrice | Price of one unit |
| ShippingAddress | Customer shipping address |
| PaymentMethod | Payment method used |
| OrderStatus | Current status of the order |
| TrackingNumber | Shipment tracking number |
| ItemsInCart | Number of items in the customer's cart |
| CouponCode | Coupon applied to the order |
| ReferralSource | Source through which the customer arrived |
| TotalPrice | Total price of the order |
